# Noche estrellada — niño con la rosa

Animated web scene inspired by Van Gogh's *The Starry Night*: a boy with a rose stands on a hill under a swirling sky.

Built with plain HTML, CSS and JavaScript (Canvas 2D), with no libraries. Everything is painted procedurally:

- The sky uses brush strokes that follow a flow field with vortices. Strokes slide along the swirls in real time.
- Stars and the moon glow and pulse.
- Yellow petals blow in the wind, and the boy's hair, scarf and rose sway.
- Moving the mouse over the sky creates a new swirl.

## Run locally

Open `index.html` in a browser. No build step is needed.
